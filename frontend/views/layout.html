About PocketWise

Application: PocketWise — Personal Finance & Shared Expense Tracker

Architecture: Classic 3-Tier Monolithic (Presentation → Application Logic → Data Tier)

Technology Stack:

  • Presentation Tier: HTML5, Vanilla JavaScript, Bootstrap 5, Chart.js
  • Application Tier: Python Flask 3.1 MVC, Parameterized Queries, Session Auth
  • Data Tier: MongoDB Atlas (NoSQL Cloud Database) with Repository Pattern

Target Users:

Designed for working professionals, freelancers, and everyday users to track daily expenses, manage monthly budget thresholds, split group expenses seamlessly, and receive heuristic financial recommendations.
